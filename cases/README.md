## 공통 원리 — 한 번만 읽기

- 모델은 지식을 **꺼내지** 않고 가장 그럴듯한 **다음 조각을 고른다**. 그래서 틀려도 유창하다(01 · 02 · 04).
- 모델이 아는 것은 **컨텍스트에 들어온 것뿐**이다. 파일에 없고 말하지 않은 것은 없는 것이다(03 · 05 · 07).
- 모델은 되묻기보다 **그럴듯한 기본값으로 채운다**. 빈칸은 추측으로 메워지고 어디에도 남지 않는다(05).
- 만든 쪽이 **스스로 채점하면 "됐다"로 기운다**. 생성과 평가를 나눈다(06).
- 되묻기("확실해?")는 또 한 번 다음 조각을 고를 뿐이다. 답은 늘 **자료** — 대조할 원문 · 근거의 범위 · 산출물 파일.
