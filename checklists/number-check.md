# 수치 확인 — 단위 · 기간 · 합계 · 비율 · 분모

> 숫자가 있는 문장은 모두 확인 대상이다. 원문 안에 분자 · 분모가 있으면 원자료 없이도 잡히는 오류가 많다 — 그것부터.

## 바로 할 수 있는 것 (원문만으로)

- [ ] **본문 안 계산** — "48,200건 중 12,050건 선정, 선정률 30%" → 12,050 ÷ 48,200 = 25.0%. 나눠 본다
- [ ] **곱셈 · 합계** — "12,050건 × 1,000만 원 = 1,205억 원" → 계산기로
- [ ] **비율의 합** — 비중 네 개를 더해 100인가(반올림 오차 ±0.2). "합계 100.1%"라고 적혀 있어도 직접 더한다
- [ ] **증감률의 합은 보지 않는다** — 비율 열은 합계를 검증 기준으로 삼지 않는다(기준 자체가 틀린 것)
- [ ] **배수 · 증가율의 두 값** — "두 배" · "17% 증가"의 전 값과 후 값이 **둘 다** 있는가. 하나만 있으면 계산 불가 → 근거 없음
- [ ] **%와 %p** — 10% → 12%는 2%p 증가이자 20% 증가. 문장이 어느 쪽인지

## 원자료와 대조

- [ ] **같은 값** — 원자료 표의 칸과 문장의 값이 같은가. 열 · 행이 한 칸 밀리지 않았는가
- [ ] **같은 단위** — 표 머리의 단위(백만 원 · 천 명)와 문장의 단위(억 원 · 명). 자릿수를 센다(2,010백만 원 = 20.1억 원)
- [ ] **같은 기간** — 표 제목의 기간과 문장의 기준일(8월 자료를 9월 기준으로 쓰지 않았는가)
- [ ] **같은 분모** — 선정률의 분모가 신청인가 접수인가. 정의가 다르면 값이 다르다
- [ ] **같은 대상** — 전체인가 일부인가 · 지역 · 연령 · 업종
- [ ] **전월 · 전년 값이 원자료에 있는가** — 비교 문장의 과거 값이 어디서 왔는지
- [ ] **무작위 10칸** — 표를 옮긴 결과는 무작위로 10칸을 골라 원자료와 대조. 행 수 · 열 합계부터

## 옮겨 쓸 때

- [ ] 모든 수치 옆에 **(표 번호 · 행 · 열)** 또는 **(출처 · 쪽)**
- [ ] 모든 수치에 **단위**와 **기준일**
- [ ] 계산 결과는 **식**과 함께("12,050 ÷ 48,200 = 25.0%")
- [ ] 반올림 자릿수를 통일

## 예방 — 장치로

- 계산은 모델이 '말로' 하지 않게 한다 — 스크립트가 원자료에서 읽어 계산하고, 대조 스크립트가 행 수 · 합계를 원자료와 맞춘다. 안 맞으면 멈춘다
- 출력 양식에 '단위' · '기준일' 열을 둔다 — 빈칸이 보이게
- 규칙 파일 한 줄: "비율 열은 합계를 내지 않는다 · 모든 수치에 단위와 기준일을 붙인다"
