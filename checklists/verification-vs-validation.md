# 검증과 확인 — A~E 체크리스트

> **검증(verification)** 은 요구 · 명세대로 만들었는가 — 기계 · 스크립트 · 검수 에이전트에 맡길 수 있다. **확인(validation)** 은 받는 사람의 필요를 채우는가 — 사람의 일이다. 하나를 통과해도 다른 하나는 남는다. A~D가 검증, E가 확인이다.

## A. 사실 · 출처 검증

- [ ] 제시된 출처(DOI · 링크 · 보고서명 · 법령 조문)가 **실제로 존재**하는가
- [ ] 출처를 열었을 때 주장한 내용이 **그 쪽에 그대로** 있는가(귀속)
- [ ] 수치 · 날짜 · 고유명사가 원문과 일치하는가
- [ ] 최신 버전 · 최신 규정인가(폐지 · 개정 · 철회 여부)
- [ ] 불확실한 부분을 "불확실" 또는 〔확인 못 함〕으로 표시했는가 — 확인 못 한 것을 확인했다고 적지 않았는가

→ [citation-check](citation-check.md) · [01 환각](../cases/01_hallucination.md) · [02 출처 오류](../cases/02_citation-failure.md)

## B. 맥락 · 적용 검증

- [ ] 국가 · 언어 · 제도 · 대상 집단이 요청과 맞는가
- [ ] 기준 시점이 자료의 시점과 같은가("현재"는 언제인가)
- [ ] 법률 · 의료 · 금융에 관한 내용을 전문가 확인 없이 그대로 쓰지 않았는가
- [ ] 요구한 출력 형식(표 · 목차 · CSV · 단위 · 기준일 열)을 지켰는가

→ [03 맥락 오류](../cases/03_context-failure.md) · [05 지시 실패](../cases/05_prompt-failure.md)

## C. 데이터 · 수치 검증

- [ ] 행 수 · 합계 · 단위 · 기간이 원자료와 일치하는가
- [ ] 계산을 **별도로 다시** 했는가(본문 안 분자 · 분모 · 스크립트)
- [ ] 비율의 합 · %와 %p · 분모 정의를 확인했는가
- [ ] 수치마다 귀속(어느 출처 · 어느 표의 값인지)을 표기했는가

→ [number-check](number-check.md) · [04 수치 오류](../cases/04_number-failure.md)

## D. 이미지 · 영상 · 보안 검증

- [ ] 글자 · 로고 · 손 · 얼굴 · 축 눈금이 왜곡되지 않았는가(확대해서)
- [ ] 인물 · 제품 일관성이 컷마다 유지되는가
- [ ] 생성물임을 표시했는가(라벨 · 메타데이터 · 출처 증명)
- [ ] 출력에 개인정보 · 키 · 내부 자료가 섞여 나오지 않았는가 · 입력 문서의 지시가 실행되지 않았는가

→ [08 이미지 · 영상](../cases/08_visual-ai-failure.md) · [09 보안 실패](../cases/09_security-failure.md)

## E. 최종 확인 — 사람의 판정

- [ ] **완료 정의**(무엇이 되면 끝인가)를 내 눈으로 확인했는가 — 에이전트의 "다 됐다"가 아니라
- [ ] 받는 사람이 이 결과로 **무엇을 결정할 수 있는가** — 맞는 답을 엉뚱한 질문에 내지 않았는가
- [ ] **인지 부채** — AI가 대신한 부분을 내가 설명할 수 있는가. 통째로 넘긴 것 중 이해가 필요한 것은 없는가
- [ ] 바뀐 것을 diff로 읽고 받아들일지 되돌릴지 **내가** 정했는가
- [ ] 공개해도 되는가 — 개인정보 · 비밀값 · 내부 자료 · 남의 원문 · 유료 자산이 없는가
- [ ] 이 결과를 **내 이름으로 책임**질 수 있는가

→ [06 완료 선언](../cases/06_completion-claim.md) · [10 과잉 자율성](../cases/10_excessive-agency.md) · [diff-review-check](diff-review-check.md) · [ethics](../ethics/ai-use-disclosure-guide.md)

## 빠른 판정 — 세 문장

1. 출처를 **실제로 열어 봤는가**
2. 숫자를 **다시 계산했는가**
3. 이 결과를 **내 이름으로 책임질 수 있는가**

## 이 저장소의 도구와의 관계

- `python tools/make_review_sheet.py 파일` — A · B · C의 "무엇을 확인할지"를 문장 단위로 뽑아 준다(판정은 하지 않는다)
- `python tools/check_review_sheet.py 원문 검토표` — 검토표의 **모양**을 검사한다(행 수 · 판정 값 · 근거 유무). 내용 판정과 E는 사람의 몫
