# AI 사용 기록 — (문서 · 과제 이름)

> 밝히는 것은 면책이 아니라 독자가 판단할 수 있게 하는 일이고, 기록은 내가 무엇을 확인했는지 남기는 일이다. 개인정보 · 내부 자료의 **내용**은 여기에 옮기지 않는다(기록은 보존하되 공개하지 않는다).

## 사용 내역

| 날짜 | 도구(이름 · 버전 또는 날짜) | 무엇을 시켰나 | 넣은 자료(종류만) | 받은 것 | 확인한 것 · 결과 | 남긴 파일 |
|---|---|---|---|---|---|---|
| 2026-__-__ | | 초안 · 요약 · 분류 · 계산 · 번역 · 이미지 | 공개 자료 / 가상 예시 / 가명 처리 사본 | | 수치 N건 중 통과 N · 미통과 N · 〔확인 못 함〕 N | out/… |
| | | | | | | |

## 검증 방법

- 수치: (원자료 파일 · 대조 방법 — 칸별 · 스크립트)
- 출처: (실재 → 귀속 → 표기 — 열어 본 것만 통과)
- 생성물: (이미지 · 영상 — 생성 표시 여부 · 손 · 글자 · 로고 · 수치 점검)

## 공개 문구 (문서에 실은 것 그대로)

> (예) 이 문서의 초안 작성에 생성형 AI(도구 이름)를 사용했다. 수치와 인용은 원자료 · 원문과 대조해 확인했으며, 확인하지 못한 항목은 〔확인 못 함〕으로 표시했다. 최종 판단과 책임은 작성자에게 있다.

## 책임
