## 확인 로그 요약

- 확인일: 2026-10-10 · 방법: 각 주소를 자동으로 열어 최종 응답 코드 기록(리디렉션 따라감) · 결과: 32건 중 200이 30건, 403이 2건(COPE · ACM)
- 본문 대조(원문 내려받아 문장 · 수치 검색): NIST AI 600-1 · OWASP 2025 PDF · Stanford 법률 연구 PDF · MIT AI Risk Repository 페이지 · GitHub 라이선스 페이지 · EU 제50조 페이지 · AI Index 페이지 · C2PA 사양 페이지 — 8건
- 정정한 것: 리서치 컬렉션의 "법률 질의 환각률 58~88%" → 원문은 **58~82%**(범용 LLM · Dahl et al. 2024 인용) · 법률 RAG 도구는 17~33%
- 쓰지 않기로 한 것: "모델 환각률 26개 모델 22~94%"(AI Index) — 찾지 못함 · "C2PA 2.4" — 버전 미확인 · "MIT 7 도메인 · 23 하위도메인" — 미확인
- 다시 확인하려면: 같은 주소 목록을 열어 응답 코드와 본문을 다시 본다. 정책 · 법령 · 수치는 개정되므로 인용 전 최신 원문을 연다
