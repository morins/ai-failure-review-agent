# 검토표 — (원문 파일 이름)

> 손으로 적는 판. 도구가 있으면 `python tools/make_review_sheet.py 파일`로 같은 모양이 나온다. 규칙은 같다 — 판정과 근거는 사람이 원문을 열어 보고 적는다 · 확인하지 못한 것은 〔확인 못 함〕.

- 원문: (경로 · 어느 답변의 어느 판인지)
- 생성: (날짜 시각) · (누가)
- 뽑은 주장: (N건 — 수치 · 출처 · 주소 · 시점 · 단정)
- 판정 값: (비움) · 통과 · 미통과 · 〔확인 못 함〕 — 통과 · 미통과에는 근거가 있어야 한다

| 번호 | 원문 줄 | 확인할 주장 | 유형 | 확인 방법 | 판정 | 근거(원자료 위치 · 계산) |
|---|---|---|---|---|---|---|
| 1 | L | | 수치 | 원자료 표 → 값 · 단위 · 기간 대조 · 다시 계산 | | |
| 2 | L | | 출처 | 실재 → 귀속(그 쪽에 그 문장) → 표기 | | |
| 3 | L | | 주소 | 열기 → 제목 · 날짜 · 그 문장 찾기 | | |
| 4 | L | | 시점 | 자료 기준일 = 문장의 시점? | | |
| 5 | L | | 단정 | 근거가 옆에 있는가 → 없으면 완화 | | |

유형별 확인 방법:

| 유형 | 무엇을 보나 | 어떻게 |
|---|---|---|
| 수치 | 값 · 단위 · 기간 · 분모 · 합계 · 비율 합 | 원자료 표를 열어 칸별로 · 본문 안 계산은 직접 나눈다 |
| 출처 | 실재 · 귀속 · 표기 · 최신 | 검색 → 열기 → Ctrl+F → 쪽 |
| 주소 | 열리는지 · 제목 · 날짜 · 그 문장 | 열어서 찾는다 |
| 시점 | 기준일 · "현재" · 개정 | 자료의 기준일과 나란히 |
| 단정 | "모든" · "확실히" · "입증" | 근거 요구 또는 〔확인 필요〕 |
