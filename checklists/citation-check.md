# 출처 확인 — 실재 · 귀속 · 표기 · 최신

> 출처 한 건을 통과시키려면 네 단계를 모두 지나야 한다. 한 단계라도 못 지나면 그 출처는 통과가 아니다 — 미통과(틀림)이거나 〔확인 못 함〕(열지 못함).

## 1 실재 — 그 문서가 있는가

- [ ] 논문: 제목 · 저자 · 연도 · 학술지로 검색 → DOI가 열리는가
- [ ] 보고서: 발행 기관 · 제목 · 연도 → 기관 사이트나 공식 저장소에서 찾을 수 있는가
- [ ] 법령: 법령 이름 · 조문 번호 · 시행일 → 공식 법령 정보에서 **그 조문**이 그 내용인가
- [ ] 뉴스 · 보도자료: 매체 · 날짜 · 제목 → 원문 기사가 있는가
- [ ] 저자는 실재하지만 **그 제목은 없는** 경우를 특히 본다(가장 그럴듯한 환각) → [01 사례](../cases/01_hallucination.md)

## 2 귀속 — 그 문서의 그 쪽에 그 문장이 있는가

- [ ] 문서를 열고 그 수치 · 그 문장을 **찾는다**(Ctrl+F). 주소가 열렸다고 통과가 아니다
- [ ] 인용된 쪽수에 있는가 → 다른 쪽이면 표기 오류, 어디에도 없으면 귀속 오류(미통과)
- [ ] 같은 지표인가 — 분모 · 대상 · 기간 · 단위가 본문 문장과 같은가(지표 혼동)
- [ ] 2차 인용("A에 따르면 B가…")은 **B 원문**을 연다. A만 보고 통과를 주지 않는다 → [02 사례](../cases/02_citation-failure.md)

## 3 표기 — 연도 · 쪽 · 판 · 저자 순서

- [ ] 연도가 문서의 발행 연도와 같은가(연도 혼입이 흔하다)
- [ ] 쪽 · 표 번호 · 그림 번호
- [ ] 저자 순서 · 공저 표기 · 기관명의 공식 표기
- [ ] 말미 목록이 아니라 **문장 옆**(인라인)에 붙어 있는가 — 어느 문장이 어느 출처인지 알 수 있어야 한다

## 4 최신 — 개정 · 잠정 · 철회

- [ ] 법령 · 지침: 시행일 · 개정 이력 — 인용한 조문이 **현행**인가
- [ ] 통계: 잠정치인가 확정치인가 · 개편으로 정의가 바뀌었는가
- [ ] 논문: 철회 · 정정 공지가 있는가
- [ ] 모델의 학습 시점 이후에 바뀐 것은 모델이 모른다 — 최신 자료는 내가 준다

## 판정 기록

| 출처 | 실재 | 귀속 | 표기 | 최신 | 판정 | 근거(쪽 · 문장) |
|---|---|---|---|---|---|---|
| | | | | | | |

- 네 칸 모두 ○ → 통과(근거 칸에 쪽과 문장)
- 하나라도 × → 미통과(어느 단계인지 근거에)
- 열지 못함 → 〔확인 못 함〕(이유를 근거에) — 통과로 적지 않는다

## 예방 — 다음 요청문에 넣을 한 줄

"인용마다 원문을 열어 쪽수와 문장을 그대로 붙여라. 열지 못한 출처는 〔확인 못 함〕으로 남기고, 말미 목록이 아니라 문장 옆에 붙여라."
