## 공통 원리 — 한 번만 읽기

- 모델은 저장된 사실을 **찾아 쓰지** 않고 확률적으로 **이어질 말을 고른다**. 그래서 틀려도 유창하다(01 · 02 · 04).
- 모델이 아는 것은 **컨텍스트에 들어온 것뿐**이다. 파일에 없고 말하지 않은 것은 없는 것이다(03 · 05 · 07).
- 모델은 **데이터와 지시를 구분하지 못한다**. 붙여 넣은 글의 한 줄이 명령이 되고, 넣은 것이 다시 나온다(09).
- 모델은 되묻기보다 **그럴듯한 기본값으로 채운다**. 적지 않은 금지는 없는 금지다(05 · 10).
- 만든 쪽이 **스스로 채점하면 "됐다"로 기운다**. 생성과 평가를 나눈다(06).
- 되묻기("확실해?")는 같은 추측을 한 번 더 시키는 것이다. 대신 **자료**를 준다 — 대조할 원문, 근거로 삼을 범위, 결과를 적을 파일.
